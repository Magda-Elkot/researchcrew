## 2026-11-13: Review of Phases 1–2 before push

| # | Decision | Why |
|---|---|---|
| 39 | All compose ports are published on `127.0.0.1` only. | Qdrant has no auth; with `0.0.0.0` anyone on the same network could read or delete the collection. Verified: not reachable from the LAN address. |
| 40 | Ingest fingerprint includes `PIPELINE_VERSION` (bump on extraction/chunking changes). `--prune` deletes documents whose PDF is gone. | 41 | `EMBEDDING_THREADS=0` means all cores (empty = default 4). | With `env_ignore_empty`, "leave empty for all cores" could never work. |
| 42 | **SPEC extension:** `get_document(doc_id, start_page=1, end_page=None, max_chars=12000)` returns a page range with `[page N]` markers, capped (1,000–50,000 chars), with `truncated`, `end_page` and the total `pages`. Text is stored per page on chunk 0 (`pages_text`); `PIPELINE_VERSION` bumped to 2. | The full text of the IRENA GCC report is ~358,000 characters (~90,000 tokens), far above Groq's free tier (~12,000 tokens/min). A safe default lets agents read long reports page by page, and the page markers help citations. Chosen by you in the pre-push review. |

## 2026-11-15: Phase 3a (MCP connectivity spike)

| # | Decision | Why |
|---|---|---|
| 61 | **Use `MCPServerAdapter` (crewai-tools), not `Agent(mcps=[...])`.** Measured with `scripts/spike_mcp.py bench` (5 calls each, warm docs-mcp): docs-mcp `search_documents` median **75 ms** (adapter, open session) vs **202 ms** (native, new connection per call); filesystem `list_directory` **2 ms** vs **827 ms** (native starts `npx` on every call). Native tool names also embed the whole server command, e.g. `npx_-y_@modelcontextprotocol/server-filesystem@2.3.0_--read-only_/media/.../data/notes_list_directory`: longer than the 64-character tool-name limit of OpenAI-style APIs, and they leak a local path into every prompt. | ~3× faster HTTP calls, ~400× faster stdio calls, clean tool names, and the tools pass through our code so the guard wrapper (#6) can wrap them. |
| 62 | **Open MCP connections once per job** (`with open_mcp_tools(...)` around a crew run), not long-lived in the API lifespan. Measured connect cost: docs-mcp **61 ms**, filesystem **870 ms** (npx start-up). | ~1 s per job is small next to a multi-minute run. Per-job sessions need no sharing between worker threads, and a restarted server is picked up by the next job without reconnect logic. |
| 63 | Tavily key in an `Authorization: Bearer` header (refines #10); `DEFAULT_PARAMETERS` header `{"max_results": 5, "search_depth": "basic"}`; only `tavily_search` exposed. (d) `BaseTool.run` fills every optional argument with `None`, and the filesystem server rejects `head: null` (this made 8 iterations fail silently). |
